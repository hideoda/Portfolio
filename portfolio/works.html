期間

2023/08~2023/11

役割

開発言語

HTML, CSS, JavaScript, PHP

フレームワーク・ライブラリー

Vue.js, Laravel

環境

Docker, PhpStorm

仕事内容

小売業界向けWebサイトの新規開発プロジェクトに参画し、主にフロントエンドの実装を担当しました。加えて、テスト仕様書の作成およびテストの実施を行いました。また、一部バックエンド処理の軽微な修正も担当しました。

実績・取り組み

  • 実装スケジュールが逼迫する中、他メンバー3名分のテストを担当し、約30時間分の開発リソースを確保。

自動車関連企業の新規Webシステムの開発

期間

2023/12~2024/05

役割

SE・PG

開発言語

HTML, CSS, JavaScript

フレームワーク・ライブラリー

Vue.js

環境

Docker, VSCode

仕事内容

自動車関連企業の新規Webシステム開発プロジェクトにおいて、フロントエンドの実装を中心に担当しました。加えて、APIテストの仕様書作成およびテスト実施も行いました。

実績・取り組み

  • フロントエンドのアーキテクチャ検討および技術選定に携わり、特にCSSフレームワークについては複数候補 （例：Tailwind CSS、Bootstrap等）を比較検討のうえ、チームの開発体制や保守性を考慮して最適な技術を提案・採用した。
  • PRレビューで得た知見やコーディング手法を案件メンバーに共有し、以後の修正対応工数を約30%削減。

人材業界向けのWebアプリケーションのリプレース

期間

2024/06~2025/08

役割

SE・PG

開発言語

HTML, CSS, PHP, JavaScript

フレームワーク

Laravel, jQuery, Vue.js

環境

Docker, VSCode

仕事内容

人材業界向けWebアプリケーションのリプレースプロジェクトにおいて、主にバックエンド全般の改修を担当しました。また、フロントエンドの実装や設計書の新規作成・修正にも携わりました。

実績・取り組み

  • フロントエンドおよびバックエンド処理の修正により、動画の保存処理を最適化。保存処理の時間を約95%短縮(120秒→5秒)。
  • 開発業務に加えて、タスク進捗を可視化するための資料作成、スケジュール管理の補佐、新規参画メンバーへの技術的なサポートも行い、プロジェクト全体の推進に貢献。
  • 本案件で得た知見を活かし、求職者・学生・若手エンジニアを対象にしたLarvel開発イベント(社外向け・参加者約20名)を主催。講師を務め、自社の技術力を体外的に発信。参加者アンケートでは満足度最高評価を獲得し、その後のカジュアル面談に繋がるなど企業認知の向上と採用活動に貢献。
